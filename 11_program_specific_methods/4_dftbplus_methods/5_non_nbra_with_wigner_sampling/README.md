# Wigner sampling for non-NBRA 
This tutorial contains the steps to perform the nonrmal modes calculation using dftb+ and its application to obtain the initial coordinates and momenta to perform the non-NBRA calcualtion using Wigner sampling.

Normal_Modes_with_DFTB+ folder contains two input files "dftb_in.hsd" for Hessian calculations and "modes_in.hsd" for normal modes calculations.

non-NBRA_wigner_sampling folder contains python files to run the non-NBRA calcualtions.

wigner_test_using_1D_harmonic_oscillator.ipynb contains the validation script of the wigner sampling using the 1D harmonic oscillator.
